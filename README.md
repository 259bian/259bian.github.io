- 简历管理

- 人岗智能匹配

等核心业务。

# 02 · Traffic Detection

## 交通标志与行人车辆检测系统


> YOLOv8 目标检测 | Python | OpenCV | AI 应用实践


### 项目角色

AI 数据处理与系统功能开发


### 项目简介

基于 YOLOv8 和 PyQt5 开发的交通场景目标检测应用。

系统支持：

- 图片检测
- 批量图片检测
- 视频检测
- 摄像头实时检测


能够识别：

- 行人
- 机动车
- 交通标志

并展示检测框、类别、置信度以及推理结果。


### 我的工作

- 参与道路场景数据集整理与数据处理

- 完成图像数据筛选、分类、标注检查及样本优化

- 分析不同场景下模型检测效果

- 针对小目标、遮挡等情况进行实验分析

- 参与 YOLOv8 模型效果评估，对比 mAP、Recall、AP 等指标

- 验证图片、视频、摄像头等不同检测流程

- 整理实验数据和项目文档


### 项目成果

- 完成交通目标检测应用开发

- 支持多种输入方式进行目标检测

- 完成 YOLOv8 多轮实验与效果分析

- 优化后模型 mAP@0.5 达到 0.955

- 各类别目标 AP 均高于 0.93


项目地址：

https://github.com/259bian/yolo-traffic-detect
